## 2) First-Run Onboarding Message (in-app or welcome email)

Welcome to PulsePlate.

Start in 3 quick steps:
1. Connect Oura
2. Set your preferences (diet style, goals, calories, allergies)
3. Generate your first plan

Tip for best results:
- Use quick preference chips before generating
- Rate meals with thumbs up/down after a plan
- Use "Regenerate with tweaks" if something feels off

Daily rhythm:
- Open PulsePlate in the morning
- Check in on how you feel
- View today's plan and commit
- Come back tomorrow for an updated plan
